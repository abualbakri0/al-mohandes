# 🤖 بوت تليجرام — تحديثات وتنزيل تطبيق "المهندس"

بوت خفيف مبني على **Node.js فقط** (بدون أي مكتبات خارجية، يعتمد على `fetch` الأصلي في Node 18+).
يتيح للمستخدمين تنزيل أحدث نسخة من التطبيق، ويرسل للمشتركين إشعاراً بكل تحديث جديد.

---

| الأمر | لمن | الوصف |
|------|------|-------|

## 🚀 التشغيل

### 1) أنشئ بوت
1. افتح [@BotFather](https://t.me/BotFather) في تليجرام.
2. أرسل `/newbot` واتبع التعليمات، ثم انسخ **التوكن (BOT_TOKEN)**.

### 2) اعرف معرّفك الرقمي
- أرسل رسالة لـ [@userinfobot](https://t.me/userinfobot) وانسخ رقم الـ **Id**.

### 3) اضبط الإعدادات
```bash
# انسخ القالب وعدّله
cp telegram-bot/.env.example telegram-bot/.env
```
ثم افتح `telegram-bot/.env` وضع:
```
BOT_TOKEN=التوكن_هنا
ADMIN_IDS=معرفك_الرقمي
```

> ملاحظة: يقرأ البوت إعداداته بالترتيب: متغيّرات البيئة ← `telegram-bot/.env` ← `.env` الجذري.
> **لا ترفع ملف `.env` إلى Git** (مُستثنى أصلاً في `.gitignore`).

### 4) شغّل البوت
```bash
node telegram-bot/bot.mjs
```
يجب أن تظهر: `🤖 بوت المهندس يعمل الآن (long polling)...`

## 📦 نشر نسخة جديدة من التطبيق

لديك طريقتان:

### أ) نشر محلي (موصى به — أسرع للملفات الكبيرة)
```bash
node telegram-bot/publish.mjs --file "المهندس-release.apk" --version 1.1 --code 21 --changelog "- إصلاح الإشعارات"
```
الخيارات:
- `--file` مسار ملف APK نسبةً لجذر المشروع **(إلزامي)**
- `--version` رقم الإصدار المعروض (إن لم يُحدَّد يُستنتج من اسم الملف)
- `--code` رقم البناء (يزيد تلقائياً إن لم يُحدَّد)
- `--changelog` نص سجل التغييرات
- `--changelogFile` مسار ملف نصي لسجل التغييرات

### ب) الرفع عبر تيليجرام
أرسل ملف `.apk` مباشرةً إلى محادثة البوت من حساب الأدمن، وسيُحفظ تلقائياً كالنسخة الحالية.

### ثم أرسل إشعاراً للمشتركين
شغّل البوت وأرسل له (كأدمن): `/notify`

## 🗂️ بنية الملفات
```
telegram-bot/
├── bot.mjs          # الملف الرئيسي (يُشغَّل)
├── config.mjs       # قراءة الإعدادات
├── api.mjs          # غلاف Telegram Bot API
├── store.mjs        # تخزين المشتركين وبيانات الإصدار (JSON)
├── publish.mjs      # نشر نسخة APK محلية
├── .env.example     # قالب الإعدادات
├── data/            # يُنشأ تلقائياً: subscribers.json + meta.json
└── releases/        # يُنشأ تلقائياً: current.apk
```

## ⚠️ ملاحظات مهمة
- **حد حجم تيليجرام:** إرسال/استقبال الملفات عبر Bot API محدود بـ **50 ميجابايت**. ملفات APK الأكبر من ذلك يجب نشرها محلياً عبر `publish.mjs` أو استخدام `DOWNLOAD_URL`.
- **التشغيل المستمر:** هذا البوت يعمل بـ long polling. لتشغيله على سيرفر 24/7 استخدم خدمة استضافة أو `pm2`/`systemd`.
- **الأمان:** احتفظ بالتوكن سرّياً ولا تشاركه. `BOT_TOKEN` في `.env` مُستثنى من Git.
