# 🤖 بوت تليجرام — تحديثات وتنزيل تطبيق "المهندس"

بوت خفيف مبني على **Node.js فقط** (بدون أي مكتبات خارجية، يعتمد على `fetch` الأصلي في Node 18+).
يتيح للمستخدمين تنزيل أحدث نسخة من التطبيق، ويرسل للمشتركين إشعاراً بكل تحديث جديد.

## 🚀 التشغيل

### 1) أنشئ بوت
1. افتح [@BotFather](https://t.me/BotFather) في تليجرام.
2. أرسل `/newbot` واتبع التعليمات، ثم انسخ **التوكن (BOT_TOKEN)**.

### 2) اعرف معرّفك الرقمي
- أرسل رسالة لـ [@userinfobot](https://t.me/userinfobot) وانسخ رقم الـ **Id**.

### 3) اضبط الإعدادات
```bash
# انسخ القالب وعدّله
cp telegram-bot/.env.example telegram-bot/.env
```
ثم افتح `telegram-bot/.env` وضع:
```
BOT_TOKEN=التوكن_هنا
ADMIN_IDS=معرفك_الرقمي
```

> ملاحظة: يقرأ البوت إعداداته بالترتيب: متغيّرات البيئة ← `telegram-bot/.env` ← `.env` الجذري.
> **لا ترفع ملف `.env` إلى Git** (مُستثنى أصلاً في `.gitignore`).

### 4) شغّل البوت
```bash
node telegram-bot/bot.mjs
```
يجب أن تظهر: `🤖 بوت المهندس يعمل الآن (long polling)...`

### 5) وصف البوت (About)
يُطبَّق وصف البوت تلقائياً عند كل تشغيل. لتطبيقه مرة واحدة فقط دون تشغيل الاستطلاع:
```bash
node telegram-bot/bot.mjs --set-description
```
أو من داخل المحادثة (كأدمن): `/setdescription`

النص المعتمد:
```
تطبيق المهندس - البوابة الأكاديمية والتقنية لطلاب هندسة الميكاترونكس والهندسة الكهربائية

📌 المطور: أبوبكر الحيدري (أبو شنب)
```
> يمكن تغييره عبر `BOT_DESCRIPTION` و`BOT_SHORT_DESCRIPTION` في `.env`.
> كما يمكن ضبطه يدوياً عبر [@BotFather](https://t.me/BotFather) → `/setdescription`.

## 🛠️ لوحة تحكم المشرف (Admin Control Panel)

تُفتح بأمر `/panel` (أو `/admin`) أو بزر **«🛠️ لوحة التحكم»** الظاهر في لوحة الأزرار **للمشرف فقط** (يُحدد المشرفون عبر `ADMIN_IDS` — غير مرئية لبقية المستخدمين، وأزرار اللوحة نفسها ترفض من غير المشرف).

### الأقسام

| القسم | ماذا يتحكم فيه |
|-------|----------------|
| 📝 النصوص والرسائل | رسالة الترحيب، رسالة التواصل، بطاقة «عن المطور»، رسائل «لا توجد نسخة»… تُحفظ وتظهر فورياً |
| 📦 بيانات التطبيق | اسم التطبيق، رقم الإصدار، تاريخ النشر، نص التحديث — تعديل ديناميكي |
| 🔘 الأزرار | تفعيل ❌/✅، تعديل النص، النقل لأعلى، الحذف (مع تأكيد)، الإضافة مع اختيار الإجراء (تنزيل/تحديث/آيفون/رابط خارجي…) |
| 🔗 الروابط | رابط iOS على Vercel ورابط التنزيل البديل — مع تحقق من صحة الرابط |
| ⚙️ وصف البوت | الوصف الكامل والمختصر + تطبيق فوري على تيليجرام |
| 📊 الإحصائيات | المشتركون (إجمالي/نشط/موقوف)، الإصدار، عدد الأزرار |
| 📣 إذاعة | بث رسالة لكل المشتركين (مع throttle وتعليم المتعثرين كمحظورين) |
| 🚀 إشعار تحديث | إرسال إشعار «تحديث جديد» بكل المشتركين |
| 📤 رفع نسخة جديدة | اعتماد نسخة APK جديدة كالنسخة الحالية (ملف ≤50MB أو **رابط تنزيل مباشر** للملفات الكبيرة) |

### 📤 رفع نسخة جديدة من التطبيق
من اللوحة اضغط **«📤 رفع نسخة جديدة (APK)»** ثم أرسل أحد الخيارين:
1. **ملف APK مباشرةً** (إن كان ≤ 50 ميجابايت — حد تيليجرام).
2. **رابط تنزيل مباشر** للملف (للملفات الكبيرة أو الاستضافة على سيرفرك) — يسحبه البوت ويعتمده تلقائياً.

يُستنتج رقم الإصدار من اسم الملف/الرابط (مثل `app-2.5.apk`)، ويُصبح الملف **النسخة الحالية** لكل المستخدمين فوراً. بعدها تظهر أزرار:
- **📝 إضافة نص التحديث** — كتابة ما الجديد في هذه النسخة.
- **🚀 إشعار كل المشتركين** — إبلاغ كل من دخل للبوت بالنسخة الجديدة.

### تدفق التعديل (بدون إعادة تشغيل أو إعادة نشر)
1. اضغط أي زر تعديل في اللوحة.
2. أرسل النص/الرابط الجديد في المحادثة (أو `/cancel` للإلغاء).
3. يُحفظ فوراً في `data/settings.json` أو `data/meta.json` ويُقرأ مع كل رسالة.

### التخزين
- **`data/settings.json`** — النصوص، الأزرار، الروابط، وصف البوت (طبقة `settings.mjs`).
- **`data/meta.json`** — الإصدار، التاريخ، النص، ملف APK (`store.mjs`).
- **`data/subscribers.json`** — المشتركون.

> **ملاحظة:** طبقة التخزين معزولة في `settings.mjs` (دوال `getSettings`/`saveSettings` فقط) —
> لاستبدالها بـ **Supabase** لاحقاً يكفي إعادة تنفيذ هاتين الدالتين بالـ REST API
> دون لمس باقي ملفات البوت.

## 📦 نشر نسخة جديدة من التطبيق

لديك طريقتان:

### أ) نشر محلي (موصى به — أسرع للملفات الكبيرة)
```bash
node telegram-bot/publish.mjs --file "المهندس-release.apk" --version 1.1 --code 21 --changelog "- إصلاح الإشعارات"
```
الخيارات:
- `--file` مسار ملف APK نسبةً لجذر المشروع **(إلزامي)**
- `--version` رقم الإصدار المعروض (إن لم يُحدَّد يُستنتج من اسم الملف)
- `--code` رقم البناء (يزيد تلقائياً إن لم يُحدَّد)
- `--changelog` نص سجل التغييرات
- `--changelogFile` مسار ملف نصي لسجل التغييرات

### ب) الرفع عبر تيليجرام
أرسل ملف `.apk` مباشرةً إلى محادثة البوت من حساب الأدمن، وسيُحفظ تلقائياً كالنسخة الحالية.

### ثم أرسل إشعاراً للمشتركين
شغّل البوت وأرسل له (كأدمن): `/notify`

## 🗂️ بنية الملفات
```
telegram-bot/
├── bot.mjs          # الملف الرئيسي (يُشغَّل)
├── panel.mjs        # لوحة تحكم المشرف (أقسام + أزرار Inline)
├── settings.mjs     # الإعدادات الديناميكية (نص/أزرار/روابط) → JSON
├── state.mjs        # الحالة المؤقتة للمشرف (وضع الإدخال)
├── config.mjs       # قراءة الإعدادات
├── api.mjs          # غلاف Telegram Bot API
├── store.mjs        # تخزين المشتركين وبيانات الإصدار (JSON)
├── publish.mjs      # نشر نسخة APK محلية
├── .env.example     # قالب الإعدادات
├── data/            # يُنشأ تلقائياً: subscribers/meta/settings.json
└── releases/        # يُنشأ تلقائياً: current.apk
```

## ⚠️ ملاحظات مهمة
- **حد حجم تيليجرام:** إرسال/استقبال الملفات عبر Bot API محدود بـ **50 ميجابايت**. ملفات APK الأكبر من ذلك يجب نشرها محلياً عبر `publish.mjs` أو استخدام `DOWNLOAD_URL`.
- **التشغيل المستمر:** هذا البوت يعمل بـ long polling. لتشغيله على سيرفر 24/7 استخدم خدمة استضافة أو `pm2`/`systemd`.
- **الأمان:** احتفظ بالتوكن سرّياً ولا تشاركه. `BOT_TOKEN` في `.env` مُستثنى من Git.
