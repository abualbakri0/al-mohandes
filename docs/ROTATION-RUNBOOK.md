## 2) المفتاح الجديد

```powershell
# من جذر المشروع
npm run key:new
# يسألك كلمة سر مرتين (12 حرفاً على الأقل) ثم يكتب android/keystore.properties تلقائياً
# وينشئ android/almohanndes-2026.keystore  (الملفان مستثنيان من Git)
```

انسخ ملف الـ keystore **فوراً** إلى مدير كلمات مرور أو قرص خارج OneDrive.
من نسخة واحدة فقط: لا تعتمد على OneDrive وحده (حساب مسروق = مفتاح مسروق).

> لا تحذف `android/almohanndes.keystore` القديم من قرصك قبل انتهاء كل شيء (للمقارنة فقط)،
> لكنه **ميت أمنياً**: لا تبنِ به ولا تنشر.

## 3) بناء v31 والتحقق

```powershell
npm run sync:android
cd android
.\gradlew.bat assembleRelease
cd ..

# تأكيد أن الـAPK موقّع بالمفتاح الجديد (قارن البصمة بما طبعه السكربت)
& "$env:JAVA_HOME\bin\keytool.exe" -printcert -jarfile android\app\build\outputs\apk\release\app-release.apk |
  Select-String 'SHA256'
```
إن ظهرت بصمة مختلفة عن التي طبعها `key:new` → لم يُقرأ `keystore.properties`، أعد الخطوة 2.

## 4) تدوير الأسرار (10 دقائق)

1. **BotFather** → `/revoke` → توكن جديد → ضعه في Railway (Variables) وأعد تشغيل الخدمة.
2. **رمز المطوّر**: شاشة الإعدادات → تغيير الرمز (يستدعي `change_dev_code` بعد خنق 6 محاولات/15د).
   - بعدها ستحتاج إدخال الرمز الجديد على جهازك، وقد تنتهي صلاحية توكين المطوّر القديم.
3. **لا تلمس** مفتاح Supabase العام (`anon`) — مضمَّن في التطبيق، وتدويره يكسر كل النسخ المثبَّتة.
4. أي كلمة سر مكتوبة في `توقيع المهندس/اقرأني-مهم.txt`: اعتبرها مسرَّبة → المفتاح الجديد يعني كلمة سر جديدة.

## 6) إغلاق القراءة ثم الفحص

```powershell
# بعد تنفيذ 20261023011000_lock_pii_reads.sql في Supabase → SQL Editor
node -e "const fs=require('fs');const t=fs.readFileSync('.env','utf8');const g=k=>(t.match(new RegExp('^'+k+'=(.*)$','m'))||[])[1]?.trim();const u=g('VITE_SUPABASE_URL'),k=g('VITE_SUPABASE_ANON_KEY');(async()=>{for(const tb of ['registrations','feedback_messages']){const r=await fetch(u+'/rest/v1/'+tb+'?select=id',{headers:{apikey:k,Authorization:'Bearer '+k}});console.log(tb,r.status);}})()"
```
النتيجة المطلوبة: `401` للجدولين (قبل التنفيذ كانت `200/206` — أي مكشوفة).
وتأكّد أن التطبيق يعمل: دخول طالب، تسجيل طالب جديد، إرسال ملاحظة، قائمة المطوّر.

## 9) أخطاء شائعة

- **`INSTALL_FAILED_UPDATE_INCOMPATIBLE`** = لم يُحذف التطبيق القديم (طبيعي ومتوقع).
- **التطبيق يرفض العمل بعد التثبيت** = `APP_SIGNER_SHA256` مضمَّن وقت البناء؛ إن بُني بدون `keystore.properties`
  يبقى فارغاً (fail-open)، وإن بُني بمفتاح مختلف عن الموقَّع يفشل. أعد البناء من نفس `keystore.properties`.
- **`keytool not found`** = عيّن `JAVA_HOME` (السكربت يبحث في jdk-17 و JBR الخاص بـAndroid Studio).
- **نسيت migration 1 قبل 2** = التطبيق الجديد يعمل، لكن القديم يفقد الدخول — لا تعكس الترتيب.
